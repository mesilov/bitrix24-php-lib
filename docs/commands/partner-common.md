# Общие принципы работы с партнёрами

## CSV-формат

Все сценарии скрейпинга и импорта работают с единым форматом CSV:

```
bitrix24_partner_number,title,site,phone,email,logo_url,detail_page_url,zone,scraped_at
3240,Hoster.KZ,https://b24.kz/,8-727-2-379-284,info@b24.kz,https://.../logo.jpg,/partners/partner/3240/,kz,2026-05-01T12:27:22+00:00
```

| Колонка | Описание |
|---------|----------|
| `bitrix24_partner_number` | Уникальный номер партнёра в Bitrix24 |
| `title` | Название компании |
| `site` | Сайт компании |
| `phone` | Телефон |
| `email` | Email |
| `logo_url` | URL логотипа |
| `detail_page_url` | Относительный путь до детальной страницы |
| `zone` | Зона Bitrix24 (`ru`, `kz`) |
| `scraped_at` | Дата/время последнего скрейпинга (ISO 8601) |

**CSV-формат фиксирован** — файлы генерируются командой `partners:scrape` (в любом режиме).

**Один файл = одна зона.** Не смешивайте партнёров с разных зон в одном CSV.

## Обнаружение блокировки

`BanDetector` отслеживает пустые страницы и определяет блокировку:

- **10+ пустых страниц подряд** — немедленная остановка
- **Более 50% пустых страниц** от общего числа — предупреждение после завершения

При блокировке увеличивайте задержку (`--request-delay`) до 2-3 секунд и повторите позже.

---

## Партнёры без детальной страницы

Если детальная страница партнёра недоступна (нет ссылки на карточку), он пропускается — не записывается в CSV. ID пропущенных партнёров выводятся в лог. Подробнее см. [partner-scraper-scenarios.md](partner-scraper-scenarios.md).

## Зоны

Параметр `--zone` выбирает домен Bitrix24:

| Зона | Домен | URL каталога партнёров |
|------|-------|------------------------|
| `ru` | `www.bitrix24.ru` | `/partners/country__19/` |
| `kz` | `www.bitrix24.kz` | `/partners/country__22/` |
